# Social-Sell-backend-project
Social Sell Backend
Welcome to the Social Sell Backend project! This backend application allows users to buy or sell social media or gaming accounts. It provides robust API endpoints for account listing, purchase, authentication, and management. The backend is built using Node.js, Express, and MongoDB.

# Features
User Authentication:

Secure user registration and login with JWT-based authentication.
Password hashing using bcrypt.
Account Listings:

Users can create, update, and delete account listings.
Listings include details like account type, price, description, and images.
Account Purchase:

Buyers can browse and purchase listed accounts.

## Tech Stack
Node.js: Backend runtime environment.
Express: Web framework for handling routes and middleware.
MongoDB: Database for storing user and listing information.
Mongoose: ODM for MongoDB.
JWT: Secure token-based authentication.
bcrypt: Password hashing.
dotenv: Environment variable management.
